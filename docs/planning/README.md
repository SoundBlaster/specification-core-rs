# Planning Inputs

This directory preserves decisions and source inventories captured before the
corresponding Flow tasks turn them into normative project documentation.

These files are planning inputs, not final policy. When a decision is approved
through Flow, move its normative form into the project charter, an ADR,
`AGENTS.md`, the contributor guide, or the relevant technical documentation.

## Documents

- [Project decisions](project-decisions.md) — accepted direction and unresolved
  questions collected from initial design discussions.
- [Documentation migration](documentation-migration.md) — inventory and planned
  mapping from Swift DocC to Rust rustdoc and mdBook.

## Ownership

- `P0-T1` consumes the product and architecture decisions.
- `P0-T2` consumes the governance and agent-operation decisions.
- `P0-T3` consumes the documentation migration inventory.
- `P0-T4` resolves the open toolchain, quality, and release questions.
- `P0-T5` audits the Swift source of truth and produces the porting matrix.
